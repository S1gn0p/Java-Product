简介

CodeCraft IDE 是一个在线 Python 代码编辑器，支持语法高亮、自动补全和实时运行代码。全部功能在浏览器中完成，不需要注册，也不需要服务器。

使用方法

  1. 在左侧编辑器中输入或粘贴 Python 代码。
  2. 点击「运行」按钮，或按 Ctrl + Enter。
  3. 运行结果显示在右侧的输出面板中。

首次点击运行时，浏览器会下载 Python 运行时（约 14MB），需要几秒钟。之后的运行会快很多。

Python 支持

运行环境基于 Pyodide（WebAssembly），内置：

项目版本
Python3.12.1
Pyodide0.26.4

标准库中的大部分模块（math、json、datetime、collections 等）可直接使用。

由于 Python 2 已停止维护，本编辑器不提供 Python 2 环境。

示例

编辑器中默认有一段代码，点击运行即可看到结果：

print("Hello, World!")

换成自己的代码试试：

for i in range(1, 6):
    print(i, "的平方是", i ** 2)

编辑器功能

  • 语法高亮：自动为 Python 代码着色
  • 自动补全：输入时提示关键字和内置函数
  • 行号与括号匹配：便于定位代码

主题

点击右上角的主题按钮可在浅色和深色主题之间切换，编辑器配色会同步变化。你的选择会被记住。

  • 浅色主题适合明亮环境
  • 深色主题减少暗光环境下的眼睛疲劳

限制说明

受浏览器沙箱限制，以下功能不可用：

  • 访问本地文件系统
  • 安装第三方包（可尝试 micropip，但速度取决于网络）
  • 长时间阻塞的循环（建议使用 await asyncio.sleep() 让出执行权）

因为所有代码都在你的浏览器中运行，不会上传到任何服务器。
