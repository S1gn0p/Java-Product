入门

了解如何使用 CodeCraft IDE 满足你的开发需求。

简介

CodeCraft IDE 是一个强大的在线代码编辑器，支持多种编程语言。它提供流畅的开发体验，具备语法高亮、自动补全和实时运行代码等功能。

试用编辑器安装指南

安装

CodeCraft IDE 是一个网页应用，无需安装任何东西。访问本站即可立即开始编写代码。

系统要求

  • 现代浏览器（Chrome、Firefox、Safari 或 Edge）
  • 网络连接
  • 启用 JavaScript

Python 支持

CodeCraft IDE 支持多个 Python 版本，通过 Pyodide（WebAssembly）在浏览器内真实执行，无需服务器：

  • Python 3.11（最新版）
  • Python 3.10
  • Python 3.9
  • Python 3.8
  • Python 2.7.18（旧版）
# Python 示例代码
def greet(name):
    return f"Hello, {name}!"

print(greet("Mundo"))

JavaScript 支持

JavaScript 代码在浏览器沙箱中真实执行，console.log 输出会显示在输出面板：

  • Node.js 20（最新版）
  • Node.js 18 LTS
// JavaScript 示例代码
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("Mundo"));

代码编辑器功能

语法高亮

为所有支持的编程语言提供自动语法高亮。

自动补全

智能代码建议，输入时自动补全。

错误检测

对支持的语言进行实时错误检测和代码检查。

主题

CodeCraft IDE 支持浅色和深色主题。你可以使用编辑器右上角的主题切换按钮在主题之间切换。

  • 浅色主题，在明亮环境下更易阅读
  • 深色主题，减少暗光环境下的眼睛疲劳
  • 根据系统偏好自动切换主题

代码执行

  • Python：基于 Pyodide（WebAssembly）在浏览器内真实运行，首次加载需下载约 14MB 运行时
  • JavaScript / TypeScript：在浏览器沙箱中执行，console.log 输出显示在输出面板
  • HTML：直接在输出面板中实时预览渲染效果
