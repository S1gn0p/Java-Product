# 拉马努金公式高精度圆周率计算器 (Java)

本项目基于拉马努金的圆周率级数公式，使用 Java 编写的高精度圆周率计算程序。
项目使用 GraalVM AOT 编译为原生可执行文件。

## ✨ 功能特性
- **极速计算**：基于拉马努金公式，每项增加约 8 位精度，采用增量滚动乘积优化。
- **内存安全**：用户可自定义分配内存大小（1GB ~ 8GB），防止内存溢出崩溃。
- **可视进度**：实时进度条展示，随时按下回车即可停止计算。
- **自动保存**：计算结果会自动保存在程序同级目录下，生成纯数字的 `pi_result.txt`。

## 🛠️ 如何从源码构建
如果你需要自行编译代码：
1. 确保已安装 JDK 25 或以上版本。
2. 编译：`javac src/Y.java`
3. 运行：`java Y`
